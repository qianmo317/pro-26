# WMS 仓库管理系统

基于 React 18 + Vite + TypeScript + Arco Design 构建的现代化仓库管理系统，采用橙色工业风主题设计。

## ✨ 功能特性

### 🎯 核心功能

- **🔐 用户认证** - 安全的登录/登出机制，支持角色权限管理
- **📥 入库管理** - 入库单创建、审批、上架全流程管理
- **📤 出库管理** - 出库单创建、拣货、复核、发运流程
- **🗺️ 库位可视化** - 直观的库位总览，实时显示库位状态
- **🔍 库存查询** - 多维度库存搜索与筛选，支持 SKU、批次、库位查询
- **📋 盘点管理** - 盘点计划创建、执行、差异处理全流程
- **📊 报表分析** - 丰富的数据可视化报表，支持多维度分析

## 🚀 快速开始

### 环境要求

- Node.js >= 18.0.0
- npm >= 9.0.0 或 pnpm >= 8.0.0

### 安装依赖

```bash
# 使用 npm
npm install

# 或使用 pnpm（推荐）
pnpm install
```

### 启动开发服务器

```bash
npm run dev
```

项目将在 `http://localhost:5173` 启动

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录

### 预览生产构建

```bash
npm run preview
```

## 📱 页面说明

### 1. 登录页 (`/login`)
- 工业风背景设计，带有动态齿轮动画效果
- 支持用户名/密码登录
- 默认账号已预填，方便快速体验

### 2. 数据总览 (`/dashboard`)
- 关键指标卡片：库位总数、SKU 总数、待处理入库/出库
- 出入库趋势图（折线图）
- 库存品类分布（环形图）
- 最近订单列表
- 进行中的盘点任务
- 各区域库位利用率（柱状图）

### 3. 入库管理 (`/inbound`)
- 入库单列表展示，支持状态筛选
- 新建入库单：选择供应商、商品、数量、批次
- 入库流程：待处理 → 进行中 → 已完成
- 入库单详情查看

### 4. 出库管理 (`/outbound`)
- 出库单列表展示，支持状态筛选
- 新建出库单：选择客户、商品、数量
- 出库流程：待处理 → 进行中 → 已完成
- 出库单详情查看

### 5. 库位总览 (`/location`)
- 库位统计概览
- 库位可视化网格展示
- 按区域筛选库位
- 库位状态图例说明
- 点击库位查看详情和库存商品

### 6. 库存查询 (`/inventory`)
- 支持按商品名称、SKU、库位搜索
- 支持按商品和库位筛选
- 库存列表展示，支持排序
- 显示查询结果统计

### 7. 盘点管理 (`/stocktake`)
- 盘点计划列表，支持状态筛选
- 创建盘点计划：选择盘点类型、区域、时间
- 盘点执行：录入实际数量，系统自动计算差异
- 盘点完成后状态更新

### 8. 报表分析 (`/report`)
- **出入库趋势** - 折线图展示近7天出入库数据
- **品类分析** - 环形图展示库存品类占比
- **库位分析** - 柱状图展示各区域库位利用率
- **商品分析** - 热门商品排行 + 库存周转分析

## 🎨 主题设计

### 橙色工业风主题

系统采用橙色为主色调，配合深色侧边栏，营造专业的工业风格：

| 颜色变量 | 值 | 用途 |
|----------|-----|------|
| `--primary-color` | `#ff7d00` | 主色调 |
| `--primary-color-hover` | `#ff9500` | 悬停色 |
| `--bg-sidebar` | `#2d3436` | 侧边栏背景 |
| `--success-color` | `#27ae60` | 成功状态 |
| `--warning-color` | `#f39c12` | 警告状态 |
| `--danger-color` | `#e74c3c` | 危险状态 |

### 设计特点
- 渐变按钮带有阴影效果
- 卡片采用圆角设计，带左侧边框强调
- 库位状态用不同颜色直观区分
- 响应式布局，适配各种屏幕尺寸

## 🔧 状态管理

系统使用 Zustand 进行状态管理，分为三个 store：

### 1. authStore (`useAuthStore`)
- 用户信息管理
- 登录/登出操作
- Token 持久化存储

### 2. appStore (`useAppStore`)
- 侧边栏折叠状态
- 当前页面标识
- 全局 UI 状态

### 3. warehouseStore (`useWarehouseStore`)
- 库位数据管理
- 库存数据管理
- 入库/出库单管理
- 盘点计划管理
- 报表数据管理

## 📊 Mock 数据说明

系统内置完整的 Mock 数据，便于开发和演示：

- **用户数据** - 1 个管理员用户
- **商品数据** - 8 种工业零件商品
- **库位数据** - 192 个库位（4个区域 × 3通道 × 4货架 × 4层）
- **库存数据** - 50 条库存记录
- **入库单** - 3 条不同状态的入库单
- **出库单** - 2 条不同状态的出库单
- **盘点计划** - 1 个进行中的盘点计划
- **报表数据** - 趋势、品类、利用率等报表数据
